# Style brief — promo Legal Management System (disetujui)

- Tema + rasa: urusan legal yang menumpuk di satu orang jadi tertata — dimengerti, lega, siap pakai.
- Konsep: tanya → jawab diegetik (dipilih). Kandidat lain: masalah → lenyap; sebelum/sesudah.
- Sidik jari: `tanya → jawab diegetik · 9 babak · HP bergetar / kartu masalah ×5 / rantai kartu berbalik / HP diam / paket + 2 UI tool / tombol · HP sudah bergetar di frame 1 · CTA diegetik (tombol ditekan)`
- Palet (dari tools): teal #0A5A61 / #0E7C86 (meja), kertas #F6FAFA, ink #16292B, aksen oranye #FFA200 (tombol tools); merah/kuning/hijau hanya di UI tools.
- Font: Fraunces (display), Plus Jakarta Sans (kartu, tombol — font UI produk), Inter (hanya UI tools).
- Penekanan: tanpa sorotan kata; kata per kata redup → penuh, dan kartu yang berbalik.
- Latar: meja teal gelap + lampu redup (masalah) → sapuan cahaya, meja terang (jawaban) → lampu padam (CTA).
- Gerak latar: cincin stempel raksasa 2 lapis berputar lambat + lampu bergeser. Tanpa butiran, tanpa blur SVG berat.
- Tanda tangan gerak: kartu mendarat dengan hentakan, lalu berbalik 3D.
- Render objek: kertas flat + bayangan lembut.
- Momen istimewa: lima kartu berbalik berantai (domino).
- Aset lokal: vendor/gsap.min.js (npm gsap 3.12.5), vendor/fonts.css + vendor/fonts/*.woff2 (npm @fontsource) — CDN diblokir di lingkungan cloud.
