# Style brief: Sistem Tata Kelola Yayasan (disetujui)

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Tata kelola yayasan. Tertib, tenang, bisa dipercaya. |
| Konsep | A: tanya → jawab diegetik + angka hidup (kandidat lain: B estafet benda, C masalah → lenyap) |
| Sidik jari struktur | tanya-jawab · 6 adegan · surat pajak, kuitansi + amplop, sertifikat + map + kunci, Excel sisa lebih, rak 172 + 3 kartu, map tertutup · pembuka: map terbuka dengan surat pajak · penutup: map menutup, segel terkunci |
| Warna | Teal `#0E7C86` (warna utama tools produk), krem `#FFF9E6` (sel input Excel). Turunan: teal tinta `#0B2F34`, teal tua `#08474D`, krem kertas `#F2E9D3`, manila `#E8D9B0`, kuning cap `#F5C84B` (krem dijenuhkan), tinta `#12313A` |
| Latar per bab | Adegan 1–3 gelap (teal tinta + lampu meja) → adegan 4–5 terang (krem kertas) → adegan 6 medan teal penuh |
| Font | Fraunces 500/600 (display) + Public Sans 500/600 (label). Dilayani lokal dari `fonts/`. |
| Penekanan teks | Tanpa pill atau garis bawah. Kata muncul redup → penuh. Kata *nol* (dan *sekarang* di CTA) berwarna kuning cap. |
| Tanda tangan gerak | Tarik dari map: benda meluncur keluar dari map, miring beberapa derajat, lalu mendarat. |
| Gerak latar | Adegan 1–3: debu naik di berkas lampu (§7c #7). Adegan 4–6: gradien krem/teal berpindah pelan (§7c #2). |
| Permukaan latar | Dua lapis atau lebih per bab, semua CSS gradient. Tanpa lapisan noise layar penuh, tanpa filter blur SVG. |
| Gaya render objek | Flat solid + bayangan kertas lembut. |
| Transisi | 1→2 kamera mendorong ke map · 2→3 map mengembalikan benda lalu mengeluarkan benda baru · 3→4 kamera turun, halaman Excel naik ke frame, latar berganti terang · 4→5 halaman Excel menyusut jadi satu lembar di rak · 5→6 kamera menembus tab teal, medan teal membuka dari tengah |
| Momen istimewa | Adegan 4: angka pajak di surat menggulung turun ke 0, disusul sapuan cahaya sekali. |
| Panggung | 1080×1350 (4:5), 26 detik, loop. |
