# Style brief: Sisa lebih, catatan ditulis langsung (disetujui)

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Catatan yang ditulis, tabel yang menghitung. Tepat, tenang, terukur. |
| Konsep | B: catatan yang ditulis langsung (#10 tanya → jawab diegetik). |
| Sidik jari struktur | tanya-jawab diegetik · 5 adegan · catatan + kursor, tiga centang, "=" + amplop → tagihan, tabel Excel dibangun + hitung mundur, 172 + tombol · pembuka: kursor berkedip di catatan kosong · penutup: tombol di atas jendela Excel yang mundur |
| Arah gaya | Brutalis mono: garis grid keras, kotak bergaris, putih kapur. |
| Warna | Putih kapur `#FBF9F1` (turunan krem `#FFF9E6`), tinta `#0C2A30`, teal `#0E7C86`, kuning cap `#F5C84B`, baris menyala `#FFF3C4`, latar penutup `#0B2F34`. |
| Font | Epilogue 600/800 (display dan teks) + JetBrains Mono 500/700 (angka tabel, label kecil). Dipilih pengguna (opsi A). |
| Penekanan teks | Stabilo kuning digambar dari kiri, hanya di "kena pajak," dan "hampir 4 tahun". |
| Tanda tangan gerak | Ketik + kursor kotak; antarbagian dengan snap. |
| Gerak latar | Garis grid bernapas (§7c #8). |
| Permukaan latar | Putih kapur + grid halus CSS (dua lapis). Tanpa noise layar penuh, tanpa blur SVG. |
| Gaya render objek | Flat bergaris tipis tegas, tanpa bayangan. |
| Transisi | 1→2 kamera menggulung · 2→3 tanda "=" membesar jadi medan teal · 3→4 medan teal naik, Excel muncul · 4→5 kamera menarik mundur, latar jadi tinta teal. |
| Momen istimewa | Adegan 4: Sisa Waktu menghitung mundur 4,0 → 0,3, baris 2021 menyala, status Mendesak. |
| Panggung | 1080×1350 (4:5), 15 detik, loop. |
