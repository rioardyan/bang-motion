# Style brief: Ketua yayasan, kalau berhenti besok (disetujui)

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Bangunan yang berdiri atau runtuh. Serius, hangat, mengintimidasi tapi jelas. |
| Konsep | B: bangunan di atas satu tiang (#7 metafora benda). |
| Sidik jari struktur | metafora benda · 5 adegan · bangunan di atas satu tiang, gelembung kutipan + miring, enam dokumen jadi pondasi, angka 172, tombol · pembuka: bangunan tenang di atas tiang · penutup: bangunan tegak di atas pondasi |
| Arah gaya | Sinematik gelap, ruang pamer: lampu sorot dari atas, lantai mengilap. |
| Warna | Arang kehijauan `#0A1517`, teal `#0E7C86`, kuning cap `#F5C84B`, krem `#FFF9E6`. |
| Font | Barlow Condensed 600/700/800 (headline, label) + Barlow 500/600 (keterangan, angka kecil). |
| Penekanan teks | Warna kata: baris terakhir headline kuning. |
| Tanda tangan gerak | Pegas teredam: benda melewati tujuan lalu bergoyang kecil sampai diam. |
| Gerak latar | Teks hantu raksasa: angka "1" lalu "172" bergeser pelan di belakang (§7c #9). Satu sapuan cahaya saat bangunan tegak. |
| Permukaan latar | Dasar arang + lampu sorot radial + pantulan lantai (CSS gradient). Tanpa noise layar penuh, tanpa blur SVG. |
| Gaya render objek | Datar 2,5D: balok dengan sisi atas terang dan sisi samping gelap, bayangan jatuh ke lantai. |
| Transisi | Dibawa benda: miring (1→2), dokumen pertama naik dan menggeser bangunan (2→3), dokumen menyatu jadi lapisan (3→4), bangunan tegak dan tombol naik (4→5). |
| Momen istimewa | Adegan 3: dokumen keenam mendarat, bangunan tegak sekali hentak, tiang KETUA tersingkir, satu sapuan cahaya. |
| Panggung | 1080×1350 (4:5), 24 detik, loop, tanpa audio. |
