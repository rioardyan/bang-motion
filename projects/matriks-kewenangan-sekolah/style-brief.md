# Style brief: Matriks kewenangan sekolah, kartu dipilah ke jalurnya

Status: **dipilih penyusun** (pengguna minta motion langsung dikerjakan setelah audio ada). Bisa direvisi.

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Dari dioper bolak-balik ke jalur yang jelas. Jenaka di masalah, rapi di jawaban. |
| Konsep | A: kartu keputusan dipilah ke jalurnya. |
| Sidik jari struktur | papan kanban · 9 adegan · tiga jalur kosong + tanda tanya, kartu dioper + gelembung chat, batas belum tertulis (garis putus-putus), batas tertulis (garis tegas), kartu-kartu meluncur ke jalurnya, halaman matriks, produk sekilas, jalur menyala bergantian, tombol · pembuka: papan kosong bertanda tanya · penutup: papan penuh dan rapi |
| Arah gaya | Papan kanban sekolah di latar navy, mengikuti warna kreatif pemenang. |
| Warna | Navy `#12284A` (latar), navy terang `#1B3763` (jalur), oranye `#F26B1D` (tanya, batas, tombol), kuning `#F5C84B` (eyebrow), krem `#FFF8EC` (kartu), teal `#0E7C86` (centang). |
| Font | Lexend 500/600/700/800 (dibuat untuk keterbacaan, cocok tema sekolah). |
| Penekanan teks | Warna kata: bagian pertanyaan headline oranye. |
| Tanda tangan gerak | Lompat oper: kartu melompat melengkung antarjalur, lalu mendarat dengan pantul kecil. |
| Gerak latar | Dua lingkaran besar samar bergeser pelan. |
| Permukaan latar | Navy datar + jalur panel. Tanpa noise, tanpa blur SVG. |
| Gaya render objek | Datar, sudut membulat, bayangan keras pendek. |
| Transisi | Dibawa benda: kartu muncul (1→2), kartu macet di tengah (2→3), garis batas digambar (3→4), kartu berdatangan (4→5), halaman matriks naik (5→6). |
| Momen istimewa | "Perjelas batas kewenangan…": garis putus-putus antarjalur berubah jadi garis oranye tegas, header jalur terkunci dengan centang. |
| Panggung | 1080×1350 (4:5), mengikuti audio (±41,7 dtk), loop. |
