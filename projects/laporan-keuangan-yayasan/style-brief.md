# Style brief: Laporan keuangan yayasan, neraca jadi timbangan

Status: **dipilih penyusun** (pengguna minta motion langsung dikerjakan setelah audio ada). Bisa direvisi.

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Malam tutup buku yang berakhir tenang. Teliti, hangat, lega. |
| Konsep | A: neraca jadi timbangan sungguhan (#7 metafora benda). |
| Sidik jari struktur | metafora benda · 7 adegan · timbangan diam, timbangan miring + selisih berubah-ubah + jam berjalan, lima lembar komponen jadi beban, baris "Selisih (harus nol)" + jarum ke 0, demo "belum nol", 172 dokumen, tombol · pembuka: timbangan diam di bawah lampu malam · penutup: timbangan rata di kertas terang |
| Arah gaya | Kertas buku besar (ledger): garis kolom hijau pucat, garis margin merah, teks di kartu memo. |
| Warna | Kertas `#F3F1E6`, garis kolom `#D3E4D6`, tinta `#1F2A2E`, teal `#0E7C86`, kuningan `#E3B23C`/`#B88A22`, merah selisih `#C8463D`, malam `#0B1F24` (lapisan gelap). |
| Font | Space Grotesk 500/600/700 (teks) + DM Mono 500 (angka, jam, sel Excel). |
| Penekanan teks | Warna kata: "selisih" merah saat belum nol, "nol"/"tidur tenang" teal. |
| Tanda tangan gerak | Ayun timbangan: miring, bergoyang teredam, lalu diam rata. |
| Gerak latar | Lampu malam menyorot timbangan; lapisan gelap memudar saat selisih jadi nol. Timbangan selalu bernapas sedikit. |
| Permukaan latar | Kertas ledger (CSS gradient). Tanpa noise, tanpa blur SVG. |
| Gaya render objek | Datar bergaris tinta, kuningan dua nada. |
| Transisi | Dibawa benda: timbangan miring (1→2), lembar komponen jatuh ke piring (2→3), baris Excel menyala (3→4), kertas terang (4→5). |
| Momen istimewa | "harus NOL": angka selisih turun ke 0, jarum ke tengah, timbangan rata sekali hentak, malam terangkat. |
| Panggung | 1080×1350 (4:5), mengikuti audio (±33,9 dtk), loop. |

Beda dari proyek lain: Satu Tiang (gelap sinematik, Barlow), Laci (ruang arsip, Fraunces), Estafet (color-block, Bricolage), Sisa lebih (catatan, Epilogue + JetBrains Mono), Tata Kelola (map arsip, Fraunces + Public Sans), Pesantren (kertas potong, Plus Jakarta Sans).
