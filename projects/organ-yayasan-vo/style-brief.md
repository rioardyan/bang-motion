# Style brief: Organ yayasan, estafet keputusan (disetujui)

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Tiga organ, satu alur. Tegas, terang, terstruktur. |
| Konsep | A: estafet keputusan (#13). Satu surat keputusan berjalan Pembina → Pengurus → Pengawas → kembali ke Pembina. |
| Sidik jari struktur | estafet keputusan · 6 adegan · surat kosong + stasiun, SOP Rapat + cap, Uraian Tugas + panah, Program Pengawasan + centang, jalur melingkar + tumpukan, tombol · pembuka: surat kosong dan chip · penutup: tombol di atas surat lengkap |
| Arah gaya | Poster color-block: tiap organ satu medan warna. |
| Warna | Teal `#0E7C86` (Pengurus), krem `#FFF9E6`. Turunan: teal tua `#0A4A52` (Pembina), kuning cap `#F5C84B` (Pengawas), putih kapur `#F6F3E8`, tinta `#0C2A30`, jingga `#E8662B` (tombol, komplementer teal). |
| Font | Bricolage Grotesque 700/800 (display) + Instrument Sans 500/600/700 (label). |
| Penekanan teks | Warna kata: "pegangan kerja yang jelas." teal. Selain itu tanpa sorotan. |
| Tanda tangan gerak | Cap mendarat: surat meluncur antarstasiun, berhenti dengan hentak, cap menempel. |
| Gerak latar | Dua bentuk geometris besar berputar lambat per medan (§7c #6). |
| Permukaan latar | Medan solid + dua bentuk lebih terang. Tanpa noise layar penuh, tanpa blur SVG. |
| Gaya render objek | Flat bergaris tegas + bayangan keras offset. |
| Transisi | Kamera menyusuri medan mengikuti surat (1→2→3→4) · kamera menarik mundur jadi peta tiga stasiun (4→5) · kamera mendorong ke stasiun Pembina (5→6). |
| Momen istimewa | Adegan 5: jalur melingkar menggambar dirinya, surat menyelesaikan satu putaran. |
| Panggung | 1080×1350 (4:5), 26 detik, loop. |
