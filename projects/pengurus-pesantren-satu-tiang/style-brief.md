# Style brief: Pengurus yayasan pesantren, satu tiang (usulan)

| Baris | Keputusan |
|---|---|
| Tema dan rasa | Dari senja yang berat ke fajar yang lega. Tenang, hangat, berharap. |
| Konsep | Format Satu Tiang (#7 metafora benda): empat unit pesantren di atas satu tiang "PENGURUS". |
| Sidik jari struktur | metafora benda · 5 adegan · empat bangunan di atas satu tiang + panah, bangunan miring + tiga butir masalah, tiga dokumen jadi pondasi, 172 + tab A–N, tombol · pembuka: kompleks pesantren senja di atas satu tiang · penutup: kompleks tegak saat fajar |
| Arah gaya | Kertas potong berlapis: siluet bukit, pohon kurma, menara; tiap lapis satu warna, bayangan lembut antar lapis. Langit senja berubah jadi fajar. |
| Warna | Malam teal tua `#0B2F34` → `#123F57` (awal). Fajar emas `#F5C84B` dan krem `#FFF9E6` (akhir). Teal `#0E7C86` (bangunan unit), hijau zaitun `#5E7B3A` (bukit), tinta `#0B2F34`. |
| Font | Plus Jakarta Sans 800 (hook, label), 500/600/700 (isi dan keterangan). |
| Penekanan teks | Warna kata: "satu orang." kuning di hook. |
| Tanda tangan gerak | Kertas melayang: dokumen turun berayun kiri-kanan seperti kertas jatuh, lalu mendarat dengan satu hentakan kecil. |
| Gerak latar | Bintang berkelip pelan dan awan kertas bergeser (§7c), lalu hilang saat fajar. |
| Permukaan latar | Gradien langit + lapisan siluet (CSS/SVG, tepi tegas). Tanpa noise layar penuh, tanpa blur SVG. |
| Gaya render objek | Kertas potong datar: tepi tegas, satu warna per lapis, bayangan lembut ke lapisan belakang. |
| Transisi | Dibawa benda: bangunan miring (1→2), dokumen pertama mendorong bangunan (2→3), dokumen menyatu jadi alas (3→4), kompleks tegak dan tombol naik dari lantai (4→5). |
| Momen istimewa | Dokumen ketiga mendarat: bangunan tegak sekali hentak, tiang "PENGURUS" tersingkir, matahari terbit dari balik bangunan dan langit berubah emas. |
| Panggung | 1080×1350 (4:5), 25 detik, loop, tanpa audio. |
