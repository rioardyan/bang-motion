# Naskah VO: Satu Tiang, Tertulis (siap ElevenLabs v4)

Suara: Bram (sama dengan Satu Tiang, supaya penonton mengenali lanjutannya). Berkas siap tempel: `vo/vo-tertulis.txt`.

Lengkung emosi: serius (hook) → cemas (pengganti menebak-nebak) → tenang (tiga hal) → jernih, berirama (pertama, kedua, ketiga) → yakin (172) → hangat dan lega (penutup) → tegas (CTA).

Durasi: ±236 suku kata, ±4,6 suku kata/detik → ±50 detik (perkiraan).

Pengucapan: "SOP" ditulis "es-o-pe" supaya tidak terbaca "sop".
